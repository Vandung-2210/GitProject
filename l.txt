[Bài tập] Xây dựng bố cục trang web với display và inline-block
Mục tiêu:
Luyện tập sử dụng display: block, inline-block, width, max-width để tạo bố cục trang web cơ bản.

Mô tả:
Tạo một file mới có tên index.html.

Tạo một file style.css để áp dụng CSS.

Thêm vào trong thẻ <body>:

Một tiêu đề <h1>, nội dung: "Bố cục trang web với display".

Một thanh điều hướng <nav> chứa 4 liên kết.

Một khối nội dung <section> chứa 3 cột sử dụng display: inline-block.

Một <footer> để hiển thị nội dung cuối trang.

Yêu cầu nộp bài:
Đưa mã nguồn lên GitHub.

Dán link repository vào phần nộp bài dưới đây.

Ví dụ mong đợi (HTML + CSS)
index.html

<!DOCTYPE html>
<html lang="vi">
<head>
    <meta charset="UTF-8">
    <title>Bố cục với display</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Bố cục trang web với display</h1>
    <nav>
        <a href="#">Trang chủ</a>
        <a href="#">Giới thiệu</a>
        <a href="#">Dịch vụ</a>
        <a href="#">Liên hệ</a>
    </nav>
    <section>
        <div class="box">Cột 1</div>
        <div class="box">Cột 2</div>
        <div class="box">Cột 3</div>
    </section>
    <footer>
        <p>Bản quyền &copy; 2024</p>
    </footer>
</body>
</html>
style.css

body {
    font-family: Arial, sans-serif;
    text-align: center;
}

nav a {
    display: inline-block;
    margin: 0 15px;
    text-decoration: none;
    color: #333;
}

section {
    margin-top: 20px;
}

.box {
    display: inline-block;
    width: 30%;
    padding: 20px;
    background-color: lightblue;
    margin: 10px;
}
